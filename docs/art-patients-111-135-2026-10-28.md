# Patient portraits 111–135

Created on 28 October 2026 with the built-in `image_gen` tool and the `imagegen` skill, in one separate request per portrait. The existing patient illustrations supplied the visual reference: a complete waist-up silhouette, folded hands, subdued period clothing and the established olive/charcoal clinic palette. Each subject is a new fictional adult. No country, city, real person or named employer is established by the artwork.

These original images were generated for Next, Please! They contain no acquired stock imagery or extracted game artwork and have no separate third-party asset attribution requirement. All runtime assets are local. No image-generation API or CLI fallback was used.

## Preparation

```sh
node scripts/prepare-patients-111-135-art.mjs /absolute/path/to/node_modules/sharp
```

The [offline recipe](../scripts/prepare-patients-111-135-art.mjs) finds the visible bounds using the established alpha > 8 margin rule, crops transparent margins and resizes to 94 × 96 with nearest-neighbor sampling. Source files and generated alpha inside the crop are preserved. The recipe rejects missing sources by default, empty images, missing alpha, opaque upper corners and duplicate runtime pixels. `--allow-missing` is available for reviewing completed images during generation. Sharp is used only for offline preparation and is not added to the project dependencies.

No face, clothing, hand or decorative pixels are invented by preparation code. The neutral contact-sheet background is only a review surface and is never loaded by the game.
