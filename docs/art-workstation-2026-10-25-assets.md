# Generated workstation sprites — 2026-10-25

This is the initial generation record. The [composition revision](art-workstation-2026-10-25-polish.md) supersedes the dark telephone, separate scale rendering and clip-holder placement. Original sources and exact prompts below remain archived; the preparation script now selects the sage telephone and tilts the holder.

Four original workstation sprites were generated specifically for Next, Please! with the built-in `image_gen.imagegen` tool and the imagegen skill. These are separate generated bitmap assets, replacing the earlier code-drawn representations. No existing-game assets, third-party stock, fonts or branding were used. The approved local title and cabinet were visual references only; their original images are unchanged.

## Reproducible preparation

Run `node scripts/prepare-workstation-sprites.mjs /absolute/path/to/node_modules/sharp`. Prepared using the cached Sharp 0.35.5 without adding a project dependency. The script locates subject bounds using alpha > 8 (ignoring near-invisible noise only for bounds), crops, and performs aspect-preserving nearest-neighbor resizing inside the runtime canvas with transparent padding. It does not remove backgrounds, repaint, recolor, create geometry, or change alpha in the retained source crop. No runtime image generation or remote assets are used.

| Source | Original size | Crop: left, top, width, height |
| --- | --- | --- |
| Phone | 1501 × 1048 | 56, 111, 1426, 832 |
| Scale | 1024 × 1536 | 304, 47, 429, 1416 |
| Holder | 1272 × 1236 | 231, 407, 855, 672 |
| Clip | 1674 × 939 | 719, 138, 247, 664 |

The object proportions are preserved; transparent padding can occupy part of a runtime canvas. Rendering must preserve nearest-neighbor sampling and integer coordinates.
