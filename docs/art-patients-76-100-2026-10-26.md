## Reproducible preparation

```sh
node scripts/prepare-patients-76-100-art.mjs /absolute/path/to/node_modules/sharp
node scripts/prepare-referral-rack-art.mjs /absolute/path/to/node_modules/sharp
```

Sharp is an offline preparation tool and is not added to runtime dependencies. Each recipe locates visible pixels at alpha > 8, crops only the transparent surrounding margin and resizes with nearest-neighbor sampling. Generated alpha inside the crop is preserved. No faces, uniforms, furniture, paper or decorative pixels are painted by code. Original source images remain unchanged. The contact-sheet background is a review aid, never a game asset.

The rack edit uses the viewed original `workstation-rack-source.png` as its edit target. It adds a stack of blank cream forms to the third tray from the top, retaining the first two full trays, empty fourth tray, wood, brass label holders and projection. The runtime renderer switches between the two generated variants according to progression; localized text remains separate from the artwork.
