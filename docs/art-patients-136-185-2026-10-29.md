# Patient portraits 136–185

Created on 29 October 2026 with the built-in `image_gen` tool and the `imagegen` skill, in one separate request per portrait. The approved patient sources were visually inspected for the established waist-up composition, folded hands, restrained period clothing and olive/charcoal clinic palette. All fifty subjects are new fictional civilian adults. Names and appearance do not establish the clinic’s country or location.

These original images were generated specifically for Next, Please! No stock imagery or extracted game artwork was acquired, and no separate third-party asset attribution is required. Runtime assets remain local. No image-generation API or CLI fallback was used.

## Preparation

```sh
node scripts/prepare-patients-136-185-art.mjs /absolute/path/to/node_modules/sharp
```

The [offline recipe](../scripts/prepare-patients-136-185-art.mjs) finds visible bounds using alpha > 8, crops transparent margins and resizes to 94 × 96 with nearest-neighbor sampling. It preserves the generated pixels and alpha within each crop. It rejects missing or empty sources, absent alpha, silhouettes touching the source boundary, opaque upper corners and duplicate runtime pixels. `--allow-missing` supports reviewing completed sources during production. Sharp is an offline tool and is not added to the project dependencies. The neutral contact-sheet background is a review surface only, never game artwork.

The batch adds 250 authored identities and 1,250 active clinical cases. The complete catalog contains 188 faces, 940 identities and 4,700 active cases plus 553 historical cases retained for imports. The existing catalog-driven loader discovers these local sprites. New daily queues prioritize unseen and least recently seen faces, with actual appearances retained across working days and save files.
